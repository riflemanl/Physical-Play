# Physical-Play
A Windows software make you joyfully play more health more!
## Installation
1. Download package from [Github release page](https://github.com/riflemanl/Physical-Play).
## Environment
1. Windows 11
2. Display fixed to Full HD 1080p is the best. Lower makes worse user experience, higher makes necessary AI computing power significantly increased.
## Usage
1. Click the installed Physical-Play software, it will show the main software window. And a window to realtime showing your body and limbs.
